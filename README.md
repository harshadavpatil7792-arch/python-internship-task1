# Expense Tracker

A simple command-line Expense Tracker built using Python. This application allows users to manage their daily expenses by storing data in a CSV file.

## Features

- Add a new expense with category
- View all saved expenses
- Search expenses by category
- Calculate total spending for each category
- Calculate monthly spending
- Store expense data in a CSV file

## Technologies Used

- Python 3
- CSV Module
- Datetime Module

## Project Files

```
Expense Tracker/
│── expense_tracker.py
│── expenses.csv
│── README.md
```

## How to Run

1. Open the project folder:
   ```
   cd Expense-Tracker
   ```

2. Run the program:
   ```
   python expense_tracker.py
   ```

## CSV Format

The expense data is stored in `expenses.csv` with the following format:

```
Description,Amount,Category,Date
Lunch,250,Food,2026-06-23
Bus Ticket,100,Travel,2026-06-23
```
